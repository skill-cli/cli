# Security

Report security-sensitive issues privately, never in a public issue.

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/skill-cli/cli/security/advisories/new).

Include:

- affected command or code path
- reproduction steps
- expected impact
- any known mitigations

## Scope

Security review is especially important for:

- skill source downloads
- archive extraction
- filesystem writes
- symlink handling
- agent prompt installation
- install lock handling
